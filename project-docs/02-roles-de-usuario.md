# 02 - Roles de Usuario

## 1. Objetivo

Este documento define los tipos de usuarios que interactúan con la plataforma 1 Millón de Amigos y las acciones que puede realizar cada uno.

Inicialmente, la plataforma contará con tres tipos principales de acceso:

1. Visitante.
2. Usuario registrado.
3. Administrador.

Una misma persona puede desempeñar diferentes actividades dentro de la plataforma sin necesidad de tener diferentes tipos de cuenta.

Por ejemplo, un usuario puede crear un proyecto solicitando ayuda y, al mismo tiempo, ayudar en los proyectos de otras personas.

---

# 2. Visitante

## 2.1 Definición

Un visitante es una persona que accede a la plataforma sin haber iniciado sesión.

Las publicaciones de 1 Millón de Amigos son públicas, por lo tanto, un visitante puede visualizar el contenido publicado dentro de la plataforma.

## 2.2 Acciones permitidas

Un visitante puede:

- Acceder a la página principal.
- Visualizar el feed de publicaciones.
- Explorar proyectos.
- Buscar publicaciones.
- Ver el detalle de una publicación.
- Ver perfiles públicos.
- Visualizar categorías.
- Acceder a enlaces públicos compartidos.

## 2.3 Acciones no permitidas

Un visitante no puede:

- Crear publicaciones.
- Comentar.
- Dar "me gusta".
- Seguir usuarios.
- Seguir proyectos.
- Dar aliento.
- Ofrecer ayuda.
- Realizar una donación.
- Enviar mensajes mediante el chat.
- Crear un perfil.
- Editar contenido.

Cuando un visitante intente realizar una acción que requiera una cuenta, el sistema deberá solicitarle registrarse o iniciar sesión.

---

# 3. Usuario registrado

## 3.1 Definición

Un usuario registrado es una persona que ha creado una cuenta dentro de 1 Millón de Amigos y ha iniciado sesión.

El usuario podrá registrarse mediante:

- Cuenta de Google.
- Cuenta de Apple.
- Registro tradicional mediante correo electrónico y contraseña.

Para el registro tradicional se solicitarán los siguientes datos:

- Nombre.
- Apellido.
- Fecha de nacimiento.
- Correo electrónico.
- Contraseña.
- Nombre de usuario.

El usuario tendrá:

- Una identidad personal mediante su nombre y apellido.
- Una identidad pública dentro de la plataforma mediante su nombre de usuario.

El correo electrónico deberá ser verificado.

---

# 4. Capacidades del usuario registrado

Un usuario registrado podrá participar en la plataforma de diferentes maneras.

## 4.1 Crear publicaciones

Todos los usuarios registrados podrán crear uno o varios proyectos o publicaciones.

Una publicación puede representar:

- Una necesidad personal.
- Una necesidad colectiva.
- Una solicitud de ayuda.
- Una causa.
- Una actividad.
- Una idea.
- Una pregunta simple.

El usuario podrá:

- Crear publicaciones.
- Guardar publicaciones como borrador.
- Publicar publicaciones.
- Editar sus propias publicaciones.
- Cerrar sus propios proyectos cuando corresponda.

Las publicaciones se publicarán automáticamente, sin requerir aprobación previa de un administrador.

---

## 4.2 Interactuar con publicaciones

Un usuario registrado podrá:

- Dar "me gusta".
- Comentar.
- Compartir.
- Seguir proyectos.
- Seguir usuarios.
- Dar aliento.
- Ofrecer ayuda.

Las formas de ayuda pueden incluir:

- Dinero.
- Bienes.
- Servicios.
- Tiempo.
- Conocimiento.
- Difusión.
- Aliento.

---

## 4.3 Comunicarse con otros usuarios

El usuario registrado podrá utilizar el sistema de chat para comunicarse con otros usuarios.

El chat permitirá coordinar diferentes formas de ayuda, incluyendo:

- Entrega de bienes.
- Prestación de servicios.
- Actividades de voluntariado.
- Intercambio de conocimientos.
- Coordinación relacionada con un proyecto.

---

## 4.4 Recibir ayuda

Un usuario que haya creado una publicación podrá recibir diferentes formas de ayuda de otros usuarios.

Dependiendo del tipo de ayuda, el proceso podrá incluir:

- Una oferta de ayuda.
- Comunicación mediante chat.
- Coordinación entre usuarios.
- Confirmación de la ayuda realizada.

Para recibir ayuda económica, el usuario deberá cumplir con los requisitos de verificación definidos para esta funcionalidad.

---

## 4.5 Perfil

Cada usuario registrado tendrá un perfil dentro de la plataforma.

El perfil podrá mostrar información relacionada con su participación, incluyendo:

- Nombre de usuario.
- Información pública del perfil.
- Publicaciones creadas.
- Proyectos apoyados.
- Actividad.
- Reconocimientos.
- Reputación.
- Participación en ayudas.

La información visible dependerá de las configuraciones de privacidad definidas para la plataforma.

---

# 5. Usuario que solicita ayuda

"Usuario que solicita ayuda" no representa un tipo de cuenta diferente.

Es una condición o actividad que puede realizar cualquier usuario registrado cuando crea una publicación o proyecto solicitando algún tipo de ayuda.

Por ejemplo:

Un mismo usuario puede:

1. Crear una publicación solicitando ayuda para una necesidad.
2. Recibir apoyo de otros usuarios.
3. Posteriormente ayudar en el proyecto de otra persona.

Por lo tanto, una misma cuenta puede ser simultáneamente:

- Creador de proyectos.
- Solicitante de ayuda.
- Persona que ayuda.
- Participante de la comunidad.

---

# 6. Usuario que ayuda

"Usuario que ayuda" tampoco representa un tipo de cuenta diferente.

Cualquier usuario registrado puede ayudar a otro usuario o proyecto mediante las diferentes formas de ayuda disponibles en la plataforma.

El usuario podrá:

- Dar aliento.
- Aportar dinero.
- Ofrecer un bien.
- Ofrecer un servicio.
- Ofrecer su tiempo.
- Compartir conocimiento.
- Ayudar a difundir una publicación.

La participación del usuario podrá ser registrada dentro de su actividad, reputación y sistema de reconocimientos.

---

# 7. Administrador

## 7.1 Definición

Un administrador es un usuario con permisos especiales para gestionar y moderar la plataforma.

El administrador tendrá acceso al panel administrativo.

---

## 7.2 Gestión de usuarios

El administrador podrá:

- Visualizar usuarios.
- Bloquear temporalmente una cuenta.
- Desbloquear una cuenta.
- Eliminar permanentemente una cuenta.

Cuando una cuenta sea bloqueada temporalmente, el usuario no podrá iniciar sesión hasta que sea desbloqueado o se determine una acción definitiva.

---

## 7.3 Gestión de publicaciones

El administrador podrá:

- Visualizar publicaciones.
- Bloquear temporalmente publicaciones.
- Desbloquear publicaciones.
- Eliminar permanentemente publicaciones.

Cuando una publicación sea bloqueada, el contenido no estará disponible públicamente.

El sistema mostrará un mensaje indicando que la publicación ha sido bloqueada.

Una publicación bloqueada podrá ser desbloqueada posteriormente por un administrador.

---

## 7.4 Gestión de denuncias

Los usuarios podrán denunciar contenido dentro de la plataforma.

El administrador podrá:

- Revisar denuncias.
- Revisar el contenido denunciado.
- Revisar al usuario involucrado.
- Bloquear temporalmente contenido.
- Eliminar contenido.
- Bloquear temporalmente una cuenta.
- Eliminar una cuenta.

---

# 8. Relación entre roles

La estructura general de roles será la siguiente:

Visitante

↓

Puede visualizar contenido público

↓

Registro / Inicio de sesión

↓

Usuario registrado

├── Crear publicaciones
├── Solicitar ayuda
├── Ayudar a otros usuarios
├── Comentar
├── Seguir
├── Compartir
├── Dar aliento
├── Comunicarse mediante chat
└── Recibir reconocimientos

↓

Administrador

├── Gestionar usuarios
├── Gestionar publicaciones
├── Revisar denuncias
└── Aplicar medidas de moderación

---

# 9. Principio general de roles

La plataforma no separa a las personas en cuentas diferentes según su función.

Un usuario registrado puede participar de múltiples maneras dentro de 1 Millón de Amigos.

La misma persona puede necesitar ayuda en un momento y ayudar a otras personas en otro momento.

El rol principal dentro de la plataforma es:

> Usuario registrado.

Las acciones que realiza el usuario determinan su participación dentro de la comunidad, pero no requieren la creación de diferentes tipos de cuenta.

El administrador es el único rol con permisos especiales de gestión y moderación.
