# 07 - Pantallas e Interfaz

## 1. Objetivo

Este documento define la identidad visual, las reglas generales de interfaz y las principales pantallas de la plataforma **1 Millón de Amigos**.

Su objetivo es mantener una experiencia visual coherente durante todo el desarrollo del proyecto.

Las decisiones visuales definidas en este documento deberán ser respetadas durante la implementación.

El sistema no deberá introducir colores, estilos o componentes arbitrarios sin mantener coherencia con esta guía.

---

# 2. Concepto visual

1 Millón de Amigos debe transmitir una combinación de:

- Confianza.
- Solidaridad.
- Cercanía.
- Esperanza.
- Comunidad.
- Profesionalismo.
- Optimismo.

La plataforma no debe parecer exclusivamente:

- Una aplicación bancaria.
- Una plataforma tradicional de crowdfunding.
- Una red social excesivamente informal.
- Una aplicación corporativa fría.

La identidad visual debe transmitir que las personas están entrando a una comunidad donde pueden:

- Pedir ayuda.
- Ofrecer ayuda.
- Compartir necesidades.
- Conectar con otras personas.
- Participar en causas.
- Generar impacto.

---

# 3. Color principal

## Azul

El color principal de la plataforma será el azul.

El azul representa:

- Confianza.
- Seguridad.
- Comunidad.
- Estabilidad.
- Profesionalismo.

Color principal:

`#2563EB`

Este color será utilizado principalmente en:

- Botones principales.
- Enlaces.
- Navegación activa.
- Elementos interactivos.
- Indicadores principales.
- Elementos de identidad de la plataforma.

# 6. Distribución del uso de colores

La interfaz deberá utilizar principalmente colores neutros.

Distribución visual aproximada:

- 70% blanco y colores neutros.
- 20% azul.
- 7% verde.
- 3% coral.

El objetivo es evitar una interfaz visualmente saturada.

Los colores de acento deberán utilizarse principalmente para acciones y estados importantes.

# 8. Tipografía

La interfaz deberá utilizar una tipografía moderna, limpia y fácil de leer.

La tipografía principal recomendada será:

**Inter**

Características:

- Moderna.
- Profesional.
- Excelente legibilidad.
- Adecuada para interfaces web.
- Compatible con pantallas de escritorio y móviles.

La jerarquía visual deberá utilizar:

- Títulos destacados.
- Subtítulos.
- Texto normal.
- Texto secundario.

No deberán utilizarse múltiples familias tipográficas innecesariamente.

La interfaz deberá mantener una apariencia limpia y consistente.

---

# 9. Estilo general

La interfaz deberá tener una apariencia:

- Moderna.
- Limpia.
- Amigable.
- Profesional.
- Humana.
- Minimalista.

Se evitará:

- Exceso de sombras.
- Demasiados colores.
- Gradientes innecesarios.
- Botones con estilos diferentes.
- Bordes excesivamente redondeados.
- Elementos decorativos sin función.

La interfaz deberá priorizar:

- Legibilidad.
- Claridad.
- Facilidad de uso.
- Acciones fácilmente identificables.

---

# 10. Tarjetas

Las publicaciones y otros elementos de contenido podrán utilizar tarjetas.

Características:

- Fondo blanco.
- Bordes suaves.
- Bordes de color neutro.
- Espaciado interno consistente.
- Sombras muy ligeras o inexistentes.

Las tarjetas deberán permitir visualizar claramente:

- Usuario.
- Contenido.
- Categoría.
- Estado.
- Interacciones.
- Acciones disponibles.

Categoría

Descripción breve del contenido...

❤️ 24   💬 8   📢 Compartir

# 13. Diseño responsive

La plataforma será desarrollada inicialmente como una aplicación web responsive.

Debe funcionar correctamente en:

- Escritorio.
- Laptop.
- Tablet.
- Teléfono móvil.

La experiencia móvil no deberá ser simplemente una reducción de la versión de escritorio.

La distribución de los elementos deberá adaptarse al tamaño de pantalla.

# 17. Estados vacíos

La plataforma deberá contemplar estados cuando no exista contenido.

Ejemplos:

## Sin publicaciones

"Actualmente no hay publicaciones."

## Sin mensajes

"Aún no tienes conversaciones."

## Sin notificaciones

"No tienes notificaciones nuevas."

Los estados vacíos deberán mantener una apariencia amigable y clara.

---

# 18. Estados de carga

Mientras la información está siendo cargada, la interfaz deberá mostrar indicadores de carga adecuados.

Se evitará dejar espacios vacíos que puedan generar confusión.

Podrán utilizarse:

- Skeletons.
- Indicadores de carga.
- Mensajes de procesamiento.

---

# 19. Mensajes de confirmación

Las acciones importantes deberán mostrar confirmación cuando corresponda.

Ejemplos:

- "Publicación creada correctamente."
- "Cambios guardados."
- "Tu ayuda ha sido registrada."
- "Mensaje enviado."
- "Cuenta bloqueada."

---

# 20. Mensajes de error

Los errores deberán mostrarse de forma clara.

Ejemplos:

- "No fue posible guardar los cambios."
- "Ocurrió un error al publicar."
- "No tienes permisos para realizar esta acción."
- "No fue posible enviar el mensaje."

Los mensajes deberán explicar el problema sin utilizar lenguaje técnico innecesario.

---

# 21. Accesibilidad

La interfaz deberá considerar:

- Contraste adecuado.
- Texto legible.
- Botones identificables.
- Navegación mediante teclado cuando corresponda.
- Estados visuales claros.
- No depender exclusivamente del color para comunicar información.

---

# 22. Principios de diseño para desarrollo con IA

Durante el desarrollo mediante herramientas de inteligencia artificial se deberán respetar las siguientes reglas:

1. No inventar nuevos colores fuera de la paleta definida sin autorización.

2. No cambiar la identidad visual entre pantallas.

3. Reutilizar componentes existentes.

4. Mantener los mismos estilos para acciones equivalentes.

5. Priorizar la experiencia móvil.

6. Mantener una interfaz limpia y profesional.

7. No agregar elementos decorativos que no tengan una función.

8. Utilizar el botón "¿Cómo puedo ayudar?" como acción principal relacionada con la colaboración.

9. Mantener consistencia en:

   - Espaciados.
   - Tipografías.
   - Botones.
   - Tarjetas.
   - Iconos.
   - Colores.

# 24. Principio visual central

La interfaz debe hacer sentir al usuario que no está simplemente navegando por una red social.

Debe transmitir que está entrando a una comunidad donde:

> Una necesidad puede convertirse en una oportunidad para que otra persona ayude.

La acción central de la plataforma será:

> **Encuentra una forma de ayudar.**

Y su identidad visual deberá apoyar esa idea sin sacrificar profesionalismo, claridad o facilidad de uso.
